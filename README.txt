- Como executar
Abra o arquivo index.html no navegador. Os dados são armazenados no localStorage do navegador.

## Observações
- Os registros são locais ao navegador/dispositivo.
- Ao excluir um veículo, o histórico de despesas e manutenções é preservado e passa a identificar o veículo como removido.
- Para testar do zero, limpe as chaves `garagem_veiculos`, `garagem_manutencoes` e `garagem_despesas` no localStorage.
